# 🏙️ Детектор скрытых объектов в городской мобильности

Проект для генерации данных городской мобильности и обнаружения скрытых 
объектов (на примере борделя) с использованием паттернов посещений.

## 📋 Описание

Проект состоит из двух основных модулей:

### 1. Симулятор (`simulator.py`)
Генерирует данные перемещений 2000 жителей города 128×128 за 30 дней:
- **Жители**: случайные дома (вне центра), работы (в центре)
- **Бордель**: 3 работницы, 40-80 клиентов с паттернами посещений
- **Шум**: 5-8 редких клеток для проверки ложных срабатываний

### 2. Детектор (`detector.py`)
Анализирует данные и находит скрытый объект по 5 метрикам:
- Ночные визиты (18:00-06:00) - 25%
- Короткие визиты (1-4 часа) - 25%
- Постоянное ядро (2-5 человек) - 20%
- Регулярность посещений (20-45 дней) - 20%
- Вечерний пик (19:00-02:00) - 10%
